# TTL 범용 28핀 스캔 테스터 배선표 (74HC, 5V)

```
Jetson ──레벨시프터──> [7414 버퍼] ──> 스캔 셀 32개 (28개 = DUT 핀 1~28, 4개 예비) ──> DUT (ZIF 28핀 소켓)
        <──레벨시프터── MISO (셀 1 의 shift FF 출력)
```

## 1. 칩 목록 (로직 17개)

| 이름 | 부품 | 용도 |
|---|---|---|
| G1-S, G2-S, G3-S, G4-S | 74HC273 ×4 | **shift FF**: 셀 1~8, 9~16, 17~24, 25~32 |
| G1-U, G2-U, G3-U, G4-U | 74HC273 ×4 | **update FF**: DUT 핀 구동 (G4-U 는 D0~D3 만 사용) |
| G1-M1, G1-M2 … G3-M2, G4-M1 | 74HC157 ×7 | shift/capture 선택 (G4-M1 = 셀 25~28) |
| B1, B2 | 74HC14 ×2 | 제어 신호 버퍼 (2단 사용 -> 반전 상쇄) |

## 2. 셀 1개 구조

```
           SE_BUF ─> 157 S (1번)          E̅ (15번) = GND
다음 셀 Q ──> B ┐
               157 Y ──> 273(S) D ──Q──┬──> 이전 셀의 mux B (셀 1 이면 MISO)
DUT 핀 ─────> A ┘   CP = SCK_BUF        └──> 273(U) D ──Q──[1kΩ]──> DUT 핀
                                              CP = UPD_BUF
```
- SE=1: 셀 c 는 셀 c+1 값을 받음 (MOSI -> 셀 32 -> … -> 셀 1 -> MISO)
- SE=0: 셀 1~28 은 **DUT 핀 노드**(1kΩ 의 DUT 쪽)를 캡처
- SPI 4바이트 = 32비트. 바이트0 MSB = 셀 1, 바이트3 LSB = 셀 32 (TX/RX 동일)

## 5. 74HC14 버퍼 (게이트 2개 직렬 = 비반전 버퍼 + 파형 정리)

| 신호 | 입력 (레벨시프터 5V 쪽 출력) | 1단 | 2단 출력 -> |
|---|---|---|---|
| SCK | B1 1번 | B1 2번 -> 3번 | **B1 4번 = SCK_BUF** |
| SE | B1 5번 | B1 6번 -> 9번 | **B1 8번 = SE_BUF** |
| UPDATE | B1 11번 | B1 10번 -> 13번 | **B1 12번 = UPD_BUF** |
| CLR_n | B2 1번 | B2 2번 -> 3번 | **B2 4번 = CLR_BUF** |
| DUT_CLK (선택) | B2 5번 | B2 6번 -> 9번 | **B2 8번 = DCLK_BUF** -> 점퍼로 DUT 클럭 핀 |
| 미사용 | B2 11, 13번 | GND 에 연결 | |

MOSI 는 셀 32(G4-S 18번 D7) 하나만 구동하므로 버퍼 없이 레벨시프터 출력 직결.

## 7. DUT 소켓 / 전원

- 셀 c 의 1kΩ DUT 쪽 노드 = ZIF 소켓 c 번 핀 = 같은 셀의 mux A 입력
- **VCC/GND 핀**: 해당 소켓 핀을 점퍼로 5V/GND 레일에 연결. 소프트웨어가 그 셀을 레일과 같은 값(1/0)으로 구동해 충돌 전류 0
- **DUT 출력 핀**: 소프트웨어가 셀 값을 직전 캡처값으로 따라가게 해서 충돌 최소화 (최악 5V/1kΩ = 5mA)
- 5V 는 별도 전원(벤치 파워/USB 5V) 권장, Jetson 5V 핀은 DUT 전류가 작을 때만
- 전원 순서: 스캔 보드 5V ON -> `reset()` (모든 셀 0) -> DUT VCC 점퍼 연결
- DIP16 칩(283/161)은 소켓 위쪽에 맞춰 꽂음: DIP 1~8번 = 소켓 1~8, DIP 9~16번 = 소켓 21~28

## 8. 조립 순서 (그룹마다 확인)

1. G1 (G1-S, G1-U, G1-M1, G1-M2) + B1/B2 + 레벨시프터 → MOSI 를 임시로 **G1-M2 13번 (셀 8 의 mux B)** 에 연결 → `python3 selftest.py --cells 8`
2. G2 추가 → MOSI 를 G2-M2 13번으로 옮기고 `--cells 16`, G3 → G3-M2 13번 `--cells 24`, G4 → 원래 위치(G4-S 18번) `--cells 32`
3. 소켓 비운 상태로 `python3 selftest.py` → 28핀 각각 구동/캡처 경로 확인
4. 74HC283 → `python3 test_283.py`, 74HC161 → `python3 test_161.py`
5. 28핀 DUT: `ttl_scan.py` 의 `DUT` 핀맵만 작성
